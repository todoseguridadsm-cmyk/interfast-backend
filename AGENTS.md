# Reglas de Interacción y Proyecto (INTERFAST)

## Idioma
- **Idioma Principal:** Español (`es`). Todas las respuestas, explicaciones, comentarios de código y documentación deben realizarse en español, salvo que se solicite expresamente lo contrario.

## Navegador Web
- **Navegador Obligatorio:** Usar siempre **Google Chrome** (`chrome.exe`) para abrir URLs, vistas previas o cualquier acción en navegador, evitando Microsoft Edge.
